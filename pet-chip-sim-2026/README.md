## 内容主线（按“先讲清品种—再讲清渠道—再讲清怎么用—最后讲清合规与实盘衔接”）

1. **开头引题**：瓶片期货新手从哪里开始练？
2. **瓶片期货基本规则**：PR、郑商所、15 吨/手、2 元/吨、±4% 涨跌停、保证金 5%→20%、日盘/夜盘时段、交割月自然人持仓为 0。
3. **为什么先练模拟盘**：产业链联动强、保证金杠杆放大盈亏、实盘开通需适当性评估。
4. **模拟盘 vs 仿真盘**：区分定义、权限适用性，提醒模拟记录一般不能直接用于开通特定品种权限。
5. **模拟盘入口渠道（4 类）**：期货公司官方 APP、第三方期货软件、Simnow、期货公司官网/公众号/客户经理。
6. **实操步骤（7 步）**：选平台→注册→登录→搜 PR 合约→看合约详情→模拟下单→复盘记录。
7. **练习重点**：合约价值、保证金分档、涨跌停与强平、限仓、交割月自然人持仓为 0、特定品种适当性。
8. **合规与风险提示**：不构成投资建议、模拟不等于实盘、权限以期货公司/交易所为准、只认持牌渠道。
9. **常见问题（FAQ）**：是否需开户、是否收费、模拟记录能否开权限、手机 vs 电脑、虚拟资金设多少。
